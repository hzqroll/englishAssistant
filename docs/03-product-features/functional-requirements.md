## 功能模块划分

### 模块 1: 导航与认证 (Navigation & Auth)
- 用户注册/登录
- 导航菜单
- 用户设置入口
- 主题切换（预留）

### 模块 2: 文本输入 (Input Panel)
- 纠正模式切换
- 智能文本框
- 字符计数
- 文件导入
- 内容清空
- 文本分析

### 模块 3: 纠错对照 (Compare Panel)
- 视图模式切换
- 错误统计展示
- 原文显示
- 纠正后文本显示
- 错误高亮
- 结果导出
- 结果保存
- 重新分析

### 模块 4: 错误分析 (Analysis Panel)
- 错误搜索
- 错误筛选
- 错误卡片展示
- 错误详情展开/折叠
- 语法规则查看
- 学习建议展示
- 学习练习跳转

### 模块 5: 布局控制 (Layout Control)
- 区域折叠/展开
- 布局快速切换（4 种预设）
- 布局状态记忆

### 模块 6: 历史记录 (History)
- 历史记录列表
- 历史详情查看
- 历史删除
- 历史筛选

### 模块 7: 统计分析 (Statistics)
- 错误统计概览
- 错误分布图表
- 进步曲线
- 学习建议

## 功能详细说明

### UC-01: 分析文本

**优先级**: P0 (MVP 必需)
**参与者**: 匿名用户、注册用户
**前置条件**: 用户打开应用

#### 主要流程
1. 用户在输入框粘贴或输入文本
2. （可选）用户切换纠正模式（准确性/自然度）
3. 用户点击"分析文本"按钮
4. 系统验证输入（非空、长度限制）
5. 系统显示分析中状态（1-3 秒）
6. 系统返回分析结果
7. 对照区显示原文和纠正后文本
8. 分析区显示错误卡片
9. 统计面板显示错误数量

#### 替代流程
- **3a. 输入为空**: 显示提示"请输入或粘贴文本"
- **3b. 文本超长**: 显示提示"文本超出 5000 字符限制，请分段处理"
- **3c. 纯中文文本**: 显示提示"请输入英文文本"
- **5a. API 错误**: 显示错误提示，建议重试

#### 后置条件
- 分析结果保存到历史（登录用户）
- 匿名用户配额减少

---

### UC-01.1: 切换纠正模式

**优先级**: P0
**参与者**: 所有用户

**功能说明**:
- **准确性优先模式**:
  - 纠正语法错误
  - 保留用户原本的语气和风格
  - 适合：考试、正式写作、语法学习

- **自然度优先模式**:
  - 改写成地道表达
  - 可能调整句子结构
  - 优化词汇选择
  - 适合：日常对话、提升表达水平

**UI 位置**: 输入框上方，模式切换开关

**默认值**: 准确性优先

---

### UC-01.2: 导入文件

**优先级**: P1 (重要)
**参与者**: 所有用户

**支持格式**:
- TXT (.txt)
- JSON (.json)
- Markdown (.md)

**流程**:
1. 用户点击"导入文件"按钮
2. 系统打开文件选择对话框
3. 用户选择文件
4. 系统读取文件内容
5. 系统将内容填充到输入框
6. 系统更新字符计数

**限制**:
- 单文件最大 5000 字符
- 超出限制则提示用户分段导入

---

### UC-01.3: 清空内容

**优先级**: P0
**参与者**: 所有用户

**流程**:
1. 用户点击"清空"按钮
2. 系统确认（可选，根据设置）
3. 系统清空输入框
4. 系统重置字符计数为 0
5. 系统清空对照区和分析区（如果有结果）

---

### UC-01.4: 查看对照结果

**优先级**: P0
**参与者**: 所有用户

**视图模式**:

#### 1. 并排对照（默认）
- **左侧**: 原文
  - 错误位置用虚线下划线高亮
  - 4 种颜色对应 4 种错误类型
  - 点击高亮词，分析区滚动到对应卡片
- **右侧**: 纠正后文本
  - 绿色显示纠正部分
  - 整体可读性强

#### 2. 仅原文
- 占满整个对照区宽度
- 错误高亮保留
- 更好的阅读体验

#### 3. 仅纠正后
- 占满整个对照区宽度
- 完整的纠正后文本
- 无高亮

---

### UC-01.5: 查看错误分析

**优先级**: P0
**参与者**: 所有用户

**错误卡片结构**:

#### 主卡片
```
┌────────────────────────────────┐
│ ◉ 语法错误           [4 个错误] │
├────────────────────────────────┤
│ ━━━ (图标)                     │
│                               │
│ 原文：go                       │
│ 纠正：went                     │
│                               │
│ 语法错误                       │
│ 主谓一致错误："We" 需要复数动词  │
│                               │
│ [展开规则 ▼]                   │
└────────────────────────────────┘
```

#### 展开后
```
┌────────────────────────────────┐
│ 语法规则                       │
│ 不规则动词 go 的过去式是 went  │
│ 类似：do → did, have → had     │
│                               │
│ [相关练习] [查看详情]          │
└────────────────────────────────┘
```

**交互**:
- 点击卡片 → 展开/折叠规则
- 悬停卡片 → 高亮文中对应错误
- 点击筛选图标 → 只显示该类型错误

   - 查看详情
   - 删除记录
   - 筛选记录

- **保存限制**: 最近 10 条（MVP）
- **保存内容**:
  - 原文
  - 纠正后文本
  - 错误详情
  - 纠正模式
  - 时间戳
  - 文本类型标签

### UC-04: 自定义布局

**优先级**: P0
**参与者**: 所有用户

#### UC-04.1: 折叠区域

**功能**: 隐藏/显示三个区域中的任何一个

**UI**: 每个区域标题栏右侧有折叠按钮 `[-]`

**折叠后**:
- 只显示标题和 `[+]` 展开按钮
- 高度约 48px

**使用场景**:
- 想专注输入时折叠分析区
- 想专注错误分析时折叠输入区
- 想专注阅读纠正后文本时折叠输入区和分析区

#### UC-04.2: 切换布局模式

**4 种预设布局**:

1. **三栏布局**（默认）
   - 输入区 25% | 对照区 45% | 分析区 30%

2. **输入 + 对照**
   - 输入区 40% | 对照区 60%
   - 分析区隐藏

3. **输入 + 分析**
   - 输入区 40% | 分析区 60%
   - 对照区隐藏

4. **全屏对照**
   - 对照区 100%
   - 输入区和分析区隐藏

**UI**: 右侧固定按钮组（4 个图标）

**记忆**: 系统记住用户最后选择的布局

#### UC-04.3: 切换视图模式

**3 种视图**:
- ⇄ 并排对照
- ⎔ 仅原文
- ✓ 仅纠正后

**UI**: 对照区顶部标签切换

### UC-07: 用户认证

**优先级**: P1
**参与者**: 未登录用户

#### 注册
1. 用户点击"登录"按钮
2. 系统显示登录/注册对话框
3. 用户选择"注册"
4. 用户输入：
   - 邮箱
   - 密码
   - 确认密码
5. 系统验证：
   - 邮箱格式
   - 密码强度
   - 邮箱是否已注册
6. 系统创建账户
7. 系统自动登录
8. 系统显示欢迎信息

#### 登录
1. 用户点击"登录"按钮
2. 用户输入：
   - 邮箱
   - 密码
3. 系统验证
4. 系统生成 JWT token
5. 系统保存 token
6. 系统更新导航栏（显示用户头像）

#### 登出
1. 用户点击用户头像
2. 用户点击"登出"
3. 系统清除 token
4. 系统返回到匿名状态
