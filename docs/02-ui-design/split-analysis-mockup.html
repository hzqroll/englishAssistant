Learning Analysis

Redundant Prepositions

You often add "about" after transitive verbs like "discuss", "mention", or "contact".

✕ discuss about
✓ discuss something
Chinglish Pattern

"How to do" is a direct translation. In English, we usually say "what to do" or "how to do it".

Pro Tip

When using "suggest", "recommend", or "explain", never use "to + person" immediately after.
❌ "Explain me" -> ✅ "Explain to me"
❌ "Reply me" -> ✅ "Reply to me"
