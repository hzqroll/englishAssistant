这种设计模仿图片中段的“四个功能卡片”逻辑，但将其扩展为更具对比性的表格或卡片组。

Prompt: > A professional SaaS feature comparison table UI. Clean, grid-based layout. The left column lists features in bold black text; the top row shows different plans or tools. Instead of heavy checkmarks, use minimalist dots or thin icons. Each cell is separated by light 1px gray borders. Alternatively, a side-by-side card layout where two products are compared with bullet points, using a light gray #F6F6F5 background for the cards.
